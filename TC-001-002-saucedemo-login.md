
## 2. SauceDemo — Тестирование авторизации

**Объект тестирования:** https://www.saucedemo.com/

**Функциональность:** форма авторизации.

**Методы:** функциональное тестирование, позитивные и негативные сценарии.

### TC-001 — Успешная авторизация

**Приоритет:** High  
**Тип:** Позитивный

**Предусловия:**
- Открыта страница https://www.saucedemo.com/
- Пользователь не авторизован.

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Ввести `standard_user` в поле Username | Логин введён |
| 2 | Ввести `secret_sauce` в поле Password | Пароль введён |
| 3 | Нажать Login | Пользователь авторизован, открыта страница каталога `/inventory.html` |

**Ожидаемый итог:** успешная авторизация, отображается каталог товаров.

### TC-002 — Авторизация с пустым паролем

**Приоритет:** High  
**Тип:** Негативный

**Предусловия:**
- Открыта страница https://www.saucedemo.com/
- Пользователь не авторизован.

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Ввести `standard_user` в поле Username | Логин введён |
| 2 | Оставить поле Password пустым | Поле пароля остаётся пустым |
| 3 | Нажать Login | Авторизация не выполняется, появляется сообщение `Epic sadface: Password is required` |

**Ожидаемый итог:** пользователь остаётся на странице авторизации, отображается сообщение об обязательном заполнении пароля.

### Применённые навыки

- Составление позитивных и негативных тест-кейсов.
- Формирование предусловий и ожидаемых результатов.
- Проверка валидации обязательных полей.
- Проверка пользовательских сценариев.
