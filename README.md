# 💼 Тестирование коммерческих продуктов

## Сэр Пуэр — интернет-магазин китайского чая

**Тип проекта:** Реальный коммерческий интернет-магазин

**Формат:** Самостоятельное исследовательское тестирование

**Объект тестирования:** Веб-приложение интернет-магазина «Сэр Пуэр»

В рамках самостоятельного тестирования исследовал функциональность интернет-магазина, работу корзины и взаимодействие клиентской части с сервером.

В ходе тестирования обнаружил и задокументировал дефекты, связанные с обработкой стоимости и количества товара.

### BUG-002 — Некорректная цена в SEO-метатегах

**Тип:** Exploratory Testing / Black-box Testing

**Инструменты:** Chrome DevTools

При исследовании интернет-магазина обнаружил расхождение между стоимостью товара на странице и значением в SEO-метатегах.

Цена в метаданных превышает фактическую в 10 раз.

Дополнительно проверил воспроизводимость дефекта на других товарах и проанализировал масштаб проблемы.

**Документация:**

- [BUG-002 — Баг-репорт (PDF)](./BUG-002-zhou-gui-aaa%20%282%29%20%281%29.pdf)
- [Анализ затронутых товаров](./prioritet.md)

---

### BUG-003 — Отсутствие серверной валидации веса товара

**Тип:** API Testing / Boundary Value Analysis

**Инструменты:** Postman, Chrome DevTools

При тестировании корзины обнаружил возможность передать через API значение веса, которое нельзя выбрать через пользовательский интерфейс.

Сервер принимает некратное значение веса, несмотря на ограничения, предусмотренные интерфейсом.

Проверил поведение системы при изменении параметров запроса и обнаружил возможность обхода ограничений выбора количества товара.

**Документация:**

- [BUG-003 — Баг-репорт (PDF)](./BUG-003-cart-quantity-validation%20%281%29.pdf)
