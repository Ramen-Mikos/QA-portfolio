# QA Portfolio

Портфолио с практическими работами по тестированию веб-приложений и интернет-магазинов.

Здесь собраны найденные дефекты, результаты исследования проблемных областей и примеры тестовой документации.

## О проекте

В рамках практики исследовался интернет-магазин. Основное внимание уделялось пользовательским сценариям, корректности отображения данных, работе корзины и взаимодействию с API.

Работы основаны на проверке реального продукта, а не только на выполнении типовых учебных заданий.

## Найденные дефекты

### BUG-002 — Завышение цены в 10 раз в SEO-метатегах

**Область:** SEO, карточка товара, обработка цен.

**Контекст обнаружения**

При проверке SEO-метатегов обратил внимание на формирование цены для товаров, продаваемых на вес. Владелец магазина заранее обозначил эту область как проблемную, поэтому она стала одним из направлений исследования.

**Исследование**

В процессе проверки обнаружил некорректное значение цены в SEO-метаданных.

Для оценки масштаба проблемы дополнительно исследовал товарные позиции. Для этого использовал Python-скрипт, созданный с помощью LLM, который помог автоматизировать сбор и обработку данных.

Результаты исследования позволили выявить затронутые товарные позиции и систематизировать их.

**Фактический результат**

В SEO-метаданные передавалась цена, завышенная в 10 раз относительно корректного значения.

**Потенциальное влияние**

Некорректные данные могли влиять на представление товаров в поисковых системах и приводить к отображению неправильной информации о стоимости.

[Подробности и доказательства](./BUG-002/)

### BUG-003 — Отсутствие валидации веса при API-запросе

**Область:** API, корзина, валидация данных.

**Описание**

При исследовании работы корзины обнаружена проблема с обработкой веса товара при отправке API-запроса.

Сервер не выполнял необходимую валидацию переданных данных, что позволяло получить некорректное значение веса и приводило к расхождению итоговой суммы в корзине.

**Фактический результат**

При передаче некорректного значения веса API принимал данные без должной проверки, вследствие чего итоговая стоимость товара рассчитывалась неправильно.

**Потенциальное влияние**

Проблема могла приводить к некорректному отображению стоимости заказа и нарушению бизнес-логики корзины.

[Подробности и доказательства](./BUG-003/)
