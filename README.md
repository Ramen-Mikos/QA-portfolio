## 📂 Практические кейсы

### BUG-002 — Некорректная цена в SEO-метатегах

**Тип:** Exploratory Testing, Black-box Testing

**Инструменты:** Chrome DevTools

При исследовании интернет-магазина обнаружено расхождение между ценой товара на странице и значением в SEO-метатегах.

Цена в метаданных превышает фактическую в 10 раз.

Дополнительно проверена повторяемость дефекта на других товарах и собраны данные для оценки масштаба проблемы.

**Документация:**

- [Баг-репорт BUG-002 (PDF)](./BUG-002-zhou-gui-aaa%20%282%29%20%281%29.pdf)
- [Анализ затронутых товаров (MD)](./prioritet.md)

### BUG-003 — Отсутствие валидации веса товара

**Тип:** API Testing, Boundary Value Analysis

**Инструменты:** Postman, Chrome DevTools

При тестировании корзины интернет-магазина обнаружена возможность передать через API некратное значение веса товара.

В результате сервер принимает значение, которое нельзя выбрать через пользовательский интерфейс.

Дополнительно выявлено расхождение в расчёте итоговой стоимости корзины.

**Документация:**

- [Баг-репорт BUG-003 (PDF)](./BUG-003-cart-quantity-validation.pdf)
